The idea in four beats

An HTTP paywall
that machines can settle.

x402 turns “Payment Required” into a protocol. PayPal Vault turns a one-time card approval into a reusable, tokenized funding source. Together they give agents a budget without giving them a wallet.

Change one field and the server returns INVALID_SIGNATURE. Reuse the challenge and it returns the cached result with no new charge.

        

      


      

        

          ◈
          
The card never touches the server

          
CardFields sends the PAN directly to PayPal. This service stores only an encrypted vault token.

        

        

          ⌁
          
Every payment is a signed intent

          
The HMAC covers resource, amount, asset, nonce and timestamp. A tampered amount fails verification.

        

        

          ↺
          
Replays can’t double-charge

          
The challenge is single-use. A replay returns cached content with X-X402-Replay: true.

        

        

          ▤
          
Budgets are enforced server-side

          
Each agent has a hard budget. The server reserves, settles or releases it around the PayPal capture.
